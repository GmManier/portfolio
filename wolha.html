Work 01 / Common AI

공용 AI [적대 몬스터]

문제
전략적 판단에는 행동이 다른 적이 필요
해결
State Tree · GAS · 데이터 테이블로 공용 AI 설계
RESULT
7종

공용 AI 하나로 만든 AI 유형

작업 방향성

전투는 익히기 쉽고, 게임 진행은 유저가 전략적으로 판단하는 잠입 액션 게임을 목표로 했습니다.

작업

행동 패턴이 다른 AI가 필요해, 하나의 구조로 여러 AI를 만드는 공용 AI를 State Tree, GAS, 데이터 테이블로 제작했습니다.

결과

공용 AI로 AI 유형 7종을 제작했고, 유형을 조합해 레벨에서 다양한 선택지를 제공했습니다.

역량상승

State Tree 이해도와 숙련도가 상승했고, 데이터 테이블을 설계 · 관리하는 역량을 쌓았습니다.

Work 02 / GAS Combat

GAS 기반 전투 시스템

문제
규칙을 고칠 때마다 드는 개발 비용
해결
GAS · 게임플레이 태그로 상태 · 이벤트 정의
RESULT
42개

정의하고 사용한 게임플레이 태그

작업 방향성

전투 시스템의 규칙을 수정하거나 추가할 때 개발 비용을 최소화하는 것이 목표였습니다.

작업

GAS와 게임플레이 태그로 전투 상태와 패링 · 가드 · 피격 같은 전투 이벤트를 정의하고, 태그로 전투 규칙을 적용했습니다.

결과

추가 구현 없이 상태 전이 규칙과 밸런스를 수정할 수 있었습니다. 42개의 태그를 정의하고 사용했습니다.

역량상승

GAS라는 언리얼 기능을 학습했고 전투 시스템을 기획하는 역량을 쌓았습니다.

전투 상태 전이도
상자 = 게임플레이 태그 · 화살표 = 전이 조건 · ↺ 끝나면 전투 대기로 복귀

Work 03 / Combat Feedback

전투 연출 시스템

목표
액션을 시각 · 청각으로 바로 피드백
해결
사운드 · 카메라 흔들림 연출 시스템 설계
RESULT
37개

사운드 · 카메라 흔들림을 적용한 몽타주

작업 방향성

유저가 액션을 받아들일 때 시각, 청각으로 바로 피드백을 받을 수 있게 하는 것을 목표로 했습니다.

작업

전투 퀄리티를 높이기 위해 사운드와 카메라 흔들림 같은 연출 시스템을 설계하고 전투에 적용했습니다.

결과

37개의 몽타주에 사운드, 카메라 흔들림을 적용했습니다.

역량상승

전투 연출, 액션감의 이해도가 상승했고 데이터 테이블을 설계 · 관리하는 역량을 쌓았습니다.
